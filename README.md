# FlowFit - Bootcamp Project

![FlowFit Logo](2.png)

FlowFit is a project developed during the bootcamp, focused on resolving a real problem. The goal of this project is to help a especific gym in Portugal, Aveiro, but can also work in every other gym.

FlowFit (Java, JavaScript, MySQL)
Developed a fully functional gym access control application in just 3 days. The system allows clients to check in and out using QR codes, while administrators can manage member status, view check-in history, and control access permissions. The backend was implemented in Java using Spring Boot to handle RESTful APIs and database logic, the frontend was built with JavaScript and HTML/CSS for user interaction, and data persistence was managed with MySQL. Emphasis was placed on clean architecture, user management, and rapid delivery under tight deadlines.
